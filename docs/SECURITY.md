# Ijazah Security Architecture

- Mobile clients never receive database credentials or AI provider secrets.
- All authenticated API operations must enforce user ownership server-side.
- Audio is uploaded through short-lived signed URLs.
- Raw recitation audio should be deleted after processing by default; retention is opt-in.
- Quran text comes from a verified corpus, never generated by an LLM.
- Tajweed scoring is separated from the explanation model: measurable speech/alignment signals first, explanation second.
- Rate limiting, audit events, abuse detection, encrypted transport, and least-privilege service credentials are required before production.
- No production claim of perfect recitation accuracy is made until benchmark evaluation passes.
